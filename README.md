# SwissetTool — Customer Demo

Standalone browser preview from SwissetTool Complete v2026.10.29.4.

## Upload
Upload **index.html** from the SwissetTool-Customer-Demo-GitHub ZIP to the repository root. Upload **.nojekyll** too (optional for this single-file page).

## Deploy
In GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

**Note:** GitHub Pages availability depends on account plan and repository visibility. For private repos on plans that don't support Pages, change visibility only after confirming there is no proprietary or sensitive material in the source.

## Safety and limitations
This is a standalone browser preview, not the network-connected Windows ERP server. Browser data stays on each device; it does not sync. Use fictional demonstration data only. Do not use for real customer, employee, pricing or drawing information. End-to-end security/quality validation remains pending.
